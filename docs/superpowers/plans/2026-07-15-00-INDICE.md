## Convenciones del repo (aplican a todos los planes)
- Stack: React 19 + Vite + TS + Tailwind + Supabase + TanStack Query. Sin admin en la PC → Node portable: `export PATH="$HOME/tools/node-v22.17.0-win-x64:$PATH"`.
- Lógica pura en `src/lib/*.ts` con test `*.test.ts` (vitest). UI en `src/features/*` y `src/components/*`.
- Migraciones SQL en la raíz `migracion-N-*.sql`, las aplica el usuario en Supabase SQL Editor.
- Cero emojis en UI (solo Lucide). Paleta monocroma (negro/blanco/gris), color solo en estados.
- Gates antes de cada deploy: `npm run test`, `npm run build`, `npm run smoke`, `npm run e2e`.
- Cada `git push` a `main` = deploy automático a Cloudflare (producción que ven los jefes).
