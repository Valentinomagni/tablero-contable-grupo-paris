### Task 1: Editar ítems de checklist (spec #3)

**Files:**
- Modify: `src/features/board/CardModal.tsx` (bloque Checklist, líneas ~154-166)

**Interfaces:**
- Consumes: `patch.mutate(p: Partial<Card>)` ya existente; tipo `ChecklistItem { txt; done; done_at }`.
- Produces: checklist editable inline (texto). La recurrencia/fecha/responsable por ítem NO existen en el modelo actual de `ChecklistItem` (solo `txt/done/done_at`); esas capacidades (frecuencia, fecha, responsable por ítem) se cubren en el **Plan 06** con el nuevo modelo de tareas recurrentes. Este task cubre editar el TEXTO sin borrar.

- [ ] **Step 1: Escribir helper puro con test** — `src/lib/checklist.ts`

```typescript
import type { ChecklistItem } from "./types";
export function editarItem(list: ChecklistItem[], idx: number, txt: string): ChecklistItem[] {
  return list.map((it, i) => (i === idx ? { ...it, txt } : it));
}
export function borrarItem(list: ChecklistItem[], idx: number): ChecklistItem[] {
  return list.filter((_, i) => i !== idx);
}
```

Test `src/lib/checklist.test.ts`:
```typescript
import { describe, it, expect } from "vitest";
import { editarItem, borrarItem } from "./checklist";
const base = [{ txt: "a", done: false, done_at: null }, { txt: "b", done: true, done_at: "x" }];
describe("editarItem", () => {
  it("cambia solo el texto del índice y preserva done", () =>
    expect(editarItem(base, 0, "a2")).toEqual([{ txt: "a2", done: false, done_at: null }, base[1]]));
});
describe("borrarItem", () => {
  it("elimina el índice", () => expect(borrarItem(base, 0)).toEqual([base[1]]));
});
```

- [ ] **Step 2: Correr el test y verificar que falla** — `npx vitest run src/lib/checklist.test.ts` → FAIL (módulo inexistente).
- [ ] **Step 3: Crear `checklist.ts`** con el código del Step 1.
- [ ] **Step 4: Verde** — `npx vitest run src/lib/checklist.test.ts` → PASS.
- [ ] **Step 5: UI editable en CardModal** — reemplazar cada `<label>` del checklist por una fila con doble modo (ver/editar). Estado local `const [editCk, setEditCk] = useState<number | null>(null); const [editTxt, setEditTxt] = useState("")`. Al hacer clic en un ícono lápiz, entra en modo edición con `<input>`; Enter o blur → `patch.mutate({ checklist: editarItem(c.checklist, n, editTxt.trim()) })`. Botón papelera → `patch.mutate({ checklist: borrarItem(c.checklist, n) })`. Import `Pencil, Trash2` de lucide-react.
- [ ] **Step 6: Build + smoke** — `npm run build && npm run smoke`.
